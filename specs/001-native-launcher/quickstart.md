# Quickstart
Use scripts/build.ps1 with the local .tools/dotnet SDK or installed .NET10 SDK.
Run regression harness before packaging. Publisher creates keys outside repository and exports
signed releases; configure brand.json with own app Client ID/update URL and public key.
Source and portable developer previews are published at https://github.com/JdeOz/aea-launcher.
Pack hosting and real authenticated gameplay remain pending. See README for verified commands.
